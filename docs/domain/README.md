# Domain

This directory contains the domain model of the project. Read
[Domain-Driven Design](../wiki/design/ddd/README.md) before you add or change a bounded context.

## Purpose

The repository factory makes repository structures and working rules for software teams. It
combines selected domain options into one repository blueprint.

## Core domain chart

| Subdomain | Type | Bounded context | Why this type |
| --- | --- | --- | --- |
| Repository factory | Core | [context-factory](context-factory/README.md) | The composition rules are the main value of the product. |
