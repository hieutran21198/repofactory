# Feature: Expert role skill

**Current version:** 1.0.0

## Summary

This feature ships a skill with the artifact-driven documentation model. With the skill, a
coding agent sets up an implementation expert role for one component from the files in the
project only. The solution expert points to the skill when no implementation expert covers a
component.
