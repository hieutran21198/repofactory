# Feature: DDD design

**Current version:** 1.0.0

## Summary

This feature adds domain-driven design (DDD) to the factory as a design method that a project
can select. A project that selects DDD gets a design guide, a shared domain model in
`docs/domain/`, and roles that do the strategic design before the tactical design.
