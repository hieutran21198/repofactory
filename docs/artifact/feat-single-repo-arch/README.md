# Feature: Single repository architecture

**Current version:** 1.1.0

## Summary

This feature adds the single repository architecture. One repository is one component: one
application, one service, or one library. Project teams use it for a project that has one
deliverable and does not need the component-type split of the multiple repositories architecture.
