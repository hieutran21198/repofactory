## Goal

Make the Nix evaluation reject each missing or conflicting governance contract.

## Steps

1. Add `artifact-release-expert` to each applicable role and expert-role list.
2. Check the canonical role sources and all rendered role outputs.
3. Check OpenCode, Claude, and Codex for all required built-in roles.
4. Check the artifact-master skill paths and its thin-loader boundary.
5. Check all coordination, message, option interview, contract review, and parallel-work fields.
6. Check the artifact release expert's ordered copy and delete procedure.
7. Check its deterministic feature README update and pre-commit verification.
8. Reject an old phase 5 route or forbidden phase 5 copy work in the solution-expert role.
9. Check the task template fields, dependency rules, parallel groups, and one-commit rule.
10. Check the canonical mixture-of-experts page and both equal layout mirrors.
11. Check both DDD page mirrors for the new phase 5 owner.
12. Keep each evaluation result as a Boolean assertion.
13. Verify each phase 2 repository-evidence assumption and record evidence in the implementation result.
14. Return an artifact correction if repository evidence disproves an assumption.

## Verify

1. Run the artifact-driven composition evaluation.
2. Confirm that all Boolean assertions pass for each selected harness and repository layout.
3. Make one required assertion false in a temporary test input.
4. Confirm that the evaluation fails for that false assertion.
5. Restore the test input and run the complete evaluation again.
6. Confirm that the final evaluation passes without the old phase 5 route.
