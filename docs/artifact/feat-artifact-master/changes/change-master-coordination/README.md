# Change: Master coordination

**Feature:** [Artifact master](../../README.md)
**From:** 3.0.0
**To:** 4.0.0
**Type:** Requirements

## Reason

The solution expert calls other subagents to coordinate feasibility
reviews and phase 4 work. This coordination is unstable on opencode.
It also costs many tokens. The team needs one stable owner for
coordination. The artifact master must own spawning and coordination
of experts. The solution expert must own phase content only. The wiki
and the expert help texts must describe this routing.
