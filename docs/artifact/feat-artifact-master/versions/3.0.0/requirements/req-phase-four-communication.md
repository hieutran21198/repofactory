# req-phase-four-communication: Communicate phase 4

**Master:** [Requirements](README.md)
**Priority:** Must
**Context:** context-factory

## Statement

The artifact master must tell the user when phase 4 starts, although phase 4 has no separate phase
plan. The start message must identify the purpose, approved input, expected output, owners, and
user actions. The artifact master must give progress messages and a phase handoff for phase 4.

## Acceptance criteria

- Given an approved phase 3 plan, when phase 4 starts, then the artifact master identifies its purpose, input, output, and owners.
- Given phase 4 without a separate phase plan, when the user reads its start message, then the message identifies required user actions.
- Given phase 4 work, when material progress occurs, then the artifact master gives useful progress information.
- Given completed phase 4 work, when the phase ends, then the artifact master gives the required phase handoff.

## Notes

The phase 3 plan is the approval gate for phase 4.
