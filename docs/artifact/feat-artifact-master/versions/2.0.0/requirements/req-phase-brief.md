# req-phase-brief: Identify each phase

**Master:** [Requirements](README.md)
**Priority:** Must
**Context:** context-factory

## Statement

Before work starts in each phase, the artifact master must identify the phase and its purpose. It
must also identify the input, expected output, and owner that apply to the phase.

## Acceptance criteria

- Given a phase plan, when the user reads it, then the user can identify the phase, purpose, input, expected output, and owner.
- Given phase 4, when the phase starts, then the user can identify the same five items.
- Given information that is not known, when the artifact master identifies the phase, then it marks that item as an open item.

## Notes

The phase number and the phase name together identify the phase.
