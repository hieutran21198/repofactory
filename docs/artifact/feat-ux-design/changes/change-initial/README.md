# Change: Initial

**Feature:** [UX Design](../../README.md)
**From:** none
**To:** 1.0.0
**Type:** Requirements

## Reason

A software team needs user experience design for a feature, but the artifact-driven workflow
has no design role and no Design artifact. The team needs an optional UX Design capability that
stays off unless selected. When selected, a designer expert must produce UX flow, layout,
interaction, and component design inside the Specs and ADRs phase, with no change to the
workflow when the option stays off.
