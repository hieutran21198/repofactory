# req-design-output: Hold UX, Layout, Interaction, Components, and Design System sections

**Master:** [Requirements](README.md)
**Priority:** Must
**Context:** context-factory

## Statement

The Design artifact must hold five sections: UX, Layout, Interaction, Components, and Design
System. The Components section must list reused components and new components. The Design System
section must list the existing tokens in use and the required additions.

## Acceptance criteria

- Given a completed Design artifact, when the team reads it, then it finds the UX, Layout, Interaction, Components, and Design System sections.
- Given a reused component, when the team reads the Components section, then it finds the reused component and its source.
- Given a new component, token, or variable, when the team reads the artifact, then it finds the new item in the Components section or in the Design System section as a required addition.

## Notes

Phase 2 owns the file layout and the contract of the Design artifact. This requirement owns the
five sections and their content only.
