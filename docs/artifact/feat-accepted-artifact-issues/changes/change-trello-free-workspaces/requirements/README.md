# Requirements: Trello Free workspaces

**Change:** [Support Trello Free workspaces](../README.md)

## Business need

A repository maintainer needs to synchronize accepted artifacts to a Trello Free workspace.

## Scope

- In scope: Use standard Trello cards, descriptions, lists, and checklists.
- In scope: Keep human-readable artifact metadata and links in each card description.
- Out of scope: Delete or change existing Custom Fields on a Trello board.

## Requirements

| ID | Requirement | Priority |
| --- | --- | --- |
| [req-support-trello-free](req-support-trello-free.md) | Trello synchronization must not require Custom Fields. | Must |
