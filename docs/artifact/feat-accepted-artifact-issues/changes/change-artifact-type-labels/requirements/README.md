# Requirements: Artifact type labels

**Change:** [Show artifact types with labels](../README.md)

## Business need

A repository maintainer needs to identify artifact types quickly in Trello and GitHub Projects.

## Scope

- In scope: Add managed type labels to GitHub issues and Trello cards.
- In scope: Preserve labels that Repofactory does not manage.
- Out of scope: Use labels as canonical artifact metadata.
- Out of scope: Use labels for artifact status or hierarchy.

## Requirements

| ID | Requirement | Priority |
| --- | --- | --- |
| [req-artifact-type-labels](req-artifact-type-labels.md) | Project items must show their artifact type with a label. | Must |
