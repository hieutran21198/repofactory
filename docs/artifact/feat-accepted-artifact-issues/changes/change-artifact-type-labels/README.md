# Change: Show artifact types with labels

**Feature:** [Accepted artifact issues](../../README.md)
**From:** 3.1.0
**To:** 4.0.0
**Type:** Requirements

## Reason

The issue body and card description contain the artifact type. A maintainer cannot quickly see the
type in a board view.

## Effect

GitHub issues and Trello cards use managed labels to show artifact types. The body or description
stays the canonical metadata store.
