# Change: Send accepted artifact notifications

**Feature:** [Accepted artifact issues](../../README.md)
**Type:** Requirements

## Reason

A maintainer can miss an accepted artifact change after a pull request merges. The project board
shows the result, but it does not send a message to the maintainer's team.

## Effect

The accepted artifact workflow can send one summary to a Google Chat space or a Slack channel.
The workflow sends the summary only after artifact synchronization succeeds.
