# Requirements: Split Trello boards

**Change:** [Split Trello planning and implementation boards](../README.md)

## Business need

A maintainer needs separate Trello views for design work and implementation work.

## Scope

- In scope: Route implementation plans and tasks to an optional second board.
- In scope: Move existing implementation cards automatically.
- Out of scope: Split GitHub Projects.

## Requirements

| ID | Requirement | Priority |
| --- | --- | --- |
| [req-split-trello-boards](req-split-trello-boards.md) | Trello synchronization must support separate planning and implementation boards. | Must |
