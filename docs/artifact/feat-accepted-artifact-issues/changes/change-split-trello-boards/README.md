# Change: Split Trello planning and implementation boards

**Feature:** [Accepted artifact issues](../../README.md)
**From:** 4.0.0
**To:** 5.0.0
**Type:** Requirements

## Reason

A maintainer needs design artifacts and implementation artifacts on separate Trello boards.

## Effect

An optional implementation board receives implementation plans and tasks. The existing board
receives all other artifacts. An empty option keeps the single-board behavior.

- [Requirements](requirements/README.md)
- [Specifications](specifications/README.md)
- [Implementation plan](tasks/README.md)
