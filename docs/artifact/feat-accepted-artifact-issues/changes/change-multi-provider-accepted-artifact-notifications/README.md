# Change: Use multiple accepted-artifact notification providers

**Feature:** [Accepted artifact issues](../../README.md)
**Type:** Requirements

## Reason

A repository maintainer can need more than one team destination for an accepted-artifact notification.
The existing provider selection permits only one destination.

## Effect

The accepted-artifact workflow can send one summary to each selected Google Chat, Slack, and Telegram provider.
