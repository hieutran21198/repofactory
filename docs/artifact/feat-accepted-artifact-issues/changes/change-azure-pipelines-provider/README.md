# Change: Add Azure Pipelines provider

**Feature:** [Accepted artifact issues](../../README.md)
**From:** 8.1.0
**To:** 9.0.0
**Type:** Requirements

## Reason

Repository teams use Azure Pipelines for continuous integration. These teams need the same
accepted-artifact issue behavior that GitHub Actions provides today. The change is additive. It
does not change GitHub Actions behavior.
