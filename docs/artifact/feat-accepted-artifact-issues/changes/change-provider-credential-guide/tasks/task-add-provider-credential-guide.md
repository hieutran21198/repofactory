# task-add-provider-credential-guide: Add the generated credential guide

**Plan:** [Implementation plan](README.md)
**Covers:** req-provider-adapters, spec-provider-credential-guide
**Context:** context-factory

## Goal

Give generated repositories a safe credential procedure for GitHub Projects and Trello.

## Steps

1. Add the provider credential page to the project-issues assets.
2. Explain the GitHub token and secret names.
3. Add the classic personal access token procedure.
4. Add the Trello API key and user token procedure.
5. Add workflow checks, rotation steps, and revocation steps.
6. Link the main project-issues page to the new procedure.
7. Emit the page with the enabled project-issues composition.

## Check

Review the commands for token exposure. Check all links and default secret names.
