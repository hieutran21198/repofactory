# Change: Provider credential guide

**Feature:** [Accepted artifact issues](../../README.md)
**From:** 1.2.0
**To:** 1.3.0
**Type:** Specifications, Decisions

## Reason

The generated setup guide names repository secrets but does not explain how to make them. Users
need a safe procedure for GitHub Projects and Trello credentials. The procedure must distinguish
local shell variables, GitHub Actions tokens, and repository secrets.
