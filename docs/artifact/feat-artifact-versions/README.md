# Feature: Artifact versions

**Current version:** none

## Summary

This feature makes a change the unit of work on a feature and adds a version folder that holds
the full state of the feature after each change. A reader who needs the current state of a
feature reads one version folder.

## Artifacts

- [Changes](changes/), one folder for each change. Read a change for the reason.
- [Versions](versions/), one folder for each version. Read the current version for the state.
