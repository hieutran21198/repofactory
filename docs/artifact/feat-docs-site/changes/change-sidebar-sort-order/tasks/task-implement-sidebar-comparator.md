## Goal

Make the generic Docusaurus asset sort every sidebar level with the specified comparator.

## Files

- `services/factory/composition/artifact-driven/docs-site/_assets/apps/documentation/docusaurus.config.js`

## Steps

1. Read `FEATURE_ORDER` from `site.featureOrder ?? []`.
2. Keep the generic asset free of repository-specific folder names and aliases.
3. Run `withIndexes` before the recursive sort operation.
4. During `withIndexes`, recover document identities from `args.docs` by document ID.
5. During `withIndexes`, recover category identities from linked documents, descendant documents,
   or category metadata.
6. Store each recovered identity in a temporary private `source` field before sorting.
7. Do not assume that a public Docusaurus sidebar item supplies `source` or `position`.
8. Resolve a document label from `item.label`, its `args.docs` title, then `item.id`.
9. Pass the identity data and parent category identity through recursive sort calls.
10. Remove any temporary private field before returning the final sidebar items.
11. Put listed feature folders first by their zero-based list position.
12. Put unlisted feature folders after listed folders.
13. Put a direct `index` or `README` document first without treating an absorbed category index as a sibling.
14. Sort phase folders as `requirements`, `specifications`, `decisions`, then `tasks`.
15. Sort valid semantic-version folders by descending major, minor, and patch numbers.
16. Put `change-initial` before the other change folders.
17. Sort all remaining items without regard to display-label case.
18. Break equal lowercase labels with the original label and then the captured source identity.
19. Compare Unicode code points with `Array.from` or `codePointAt`. Do not use `localeCompare` or
   a `charCodeAt` loop.
20. Apply each special rule only to its specified item type and parent folder.
21. Keep all other Docusaurus settings unchanged.
22. Regenerate `apps/documentation/docusaurus.config.js` through the factory copy operation.
23. Do not hand-edit the generated copy. Keep its regenerated bytes for the phase 4 commit.

## Check

The extracted rendered menus must have the specified order.
