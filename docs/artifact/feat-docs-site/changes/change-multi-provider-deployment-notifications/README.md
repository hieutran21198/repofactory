# Change: Use multiple deployment notification providers

**Feature:** [Documentation site](../../README.md)
**Type:** Requirements

## Reason

A repository maintainer can need more than one team destination for a deployment notification.
The existing provider selection permits only one destination.

## Effect

The documentation site workflow can send one deployment message to each selected Google Chat,
Slack, and Telegram provider after a successful deployment.
