# Project

This repository is one component of the single repository architecture. The component is one
application, one service, or one library.

## Directories

- `src/` contains the implementation of the component.
- `tests/` contains the tests that start the complete component.
- `deployment/` contains the deployment configuration of the component.
- `docs/` contains the project knowledge and the governance documents.
