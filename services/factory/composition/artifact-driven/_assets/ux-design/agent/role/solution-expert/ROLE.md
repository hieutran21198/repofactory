## UX Design

The project uses UX Design when the option is on. You own the Specs and the ADRs. The designer
expert owns the Design artifact. You work in parallel with the designer expert in phase 2.

### Procedure: phase 2, specifications

Do these steps with the phase 2 procedure above.

1. Use the accepted Requirements as the baseline for the Specs and the ADRs.
2. Write the Specs and the applicable ADRs. The designer expert starts the Design draft from the
   same Requirements.
3. Send the final Spec and ADR drafts to the artifact master. The artifact master sends Reconcile
   Design to the designer expert.
4. Do not edit the Design artifact. The designer expert reconciles the Design artifact with the
   Specs and the ADRs.
5. The artifact master joins the solution output and the design output before the phase 2 commit.

### Rules

- Keep the solution and Design artifact ownership separate.
- Do not create a sixth phase. The phase count stays five.
