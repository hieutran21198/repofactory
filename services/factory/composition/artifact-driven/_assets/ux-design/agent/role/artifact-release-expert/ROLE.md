## UX Design

The project uses UX Design when the option is on. The change holds a `design/` folder. Add it to
the phase 5 copy.

### Procedure: phase 5, version

In step 3 of the phase 5 procedure above, also copy the `design/` folder of the change over the
new version when the folder exists. A file with the same path replaces the file in the copy.

### Rules

- Copy and delete only. Do not edit the copied Design artifact.
- Do not run a design step.
- Do not create a sixth phase. The phase count stays five.
