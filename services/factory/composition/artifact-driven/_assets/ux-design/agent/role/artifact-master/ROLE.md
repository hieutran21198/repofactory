## UX Design

The project uses UX Design when the option is on. You own no Design content. You route the Design
work and join the phase 2 output.

### Procedure

1. Plan-P2 and Build-P2 go to the solution expert and the designer expert. Give both experts the
   accepted Requirements from phase 1.
2. Start the solution expert and the designer expert in parallel. The solution expert writes the
   Specs and the applicable ADRs. The designer expert writes the Design draft.
3. When the final Spec and ADR drafts exist, send Reconcile Design to the designer expert. Give
   the final Spec and ADR paths.
4. The designer expert reconciles the Design artifact with those constraints.
5. Join the solution output and the design output before the phase 2 commit. Do not commit phase 2
   when one output is absent.
6. Do not create a sixth phase. The phase count stays five.
